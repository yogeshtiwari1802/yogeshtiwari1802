### 🧑‍💻 About me

- 🔭 I'm building **[AnkBodh](https://ankbodh.com)**: live market breadth, vega and option-premium charts for NIFTY, SENSEX, BANKNIFTY and MIDCPNIFTY, updated every minute of the session
- ⚡ I focus on **systematic and high-frequency trading**, with millisecond execution across the whole path: detection → scanning → order
- 🛠️ I build my own trading tools rather than relying on off-the-shelf software
- 📈 I work where software development meets NSE/BSE options & F&O trading
- ☁️ My tools run on a cloud VM in the Mumbai region from 09:05 to 15:45 IST, with live data streamed over WebSockets
- 🌱 Currently exploring option vega as a signal, and how to test trading rules honestly (no look-ahead, real charges, real fills)
- 🚀 I'm also working on new ventures in consumer health tech and design-led furniture
- 👯 Looking to collaborate on **options analytics, market-data pipelines and honest strategy research**
- 💬 Ask me about **algo trading, market breadth, broker APIs, market scanners, Python automation**
- 😄 Fun fact: *AnkBodh* is Hindi for "number sense": **Ank** (numbers) + **Bodh** (understanding). Hence the tagline, *Numbers, understood.*

---

### 🔧 What I've built

| Project | What it does |
|---|---|
| **[AnkBodh](https://ankbodh.com)** | Public web app: breadth workspace charts, signals, scanner and day-wrap pictures, with sign-in and an admin area (FastAPI, SQLite, Next.js, lightweight-charts) |
| **Breadth & Vega Scanner** | Reads index breadth and option vega every minute and records paper trades with stops, margin and capital limits |
| **Live Trader** | Sends approved trades to two brokers as LIMIT orders, handling partial fills and protective stops |
| **Market Structure Scanner** | Scans ~200 F&O stocks for trend, relative strength, and market-structure (BOS/CHoCH) signals |
| **Copy-Trader** | Mirrors orders between two Indian brokers in real time |
| **Live OI Tracker** | Streams option open-interest data into a dashboard for overnight positioning and intraday signals |
| **Research tools** | Replays strategies on archived minute data, after charges and slippage |

> The trading code lives in private repositories; AnkBodh is the public face of it.
